# 01. 도면 (화면 설계)

모바일 기준 360px 폭. 한 화면에 한 가지 일만 한다.

## 화면 목록

| # | 화면 | 누가 | 목적 |
|---|---|---|---|
| S1 | 입력 | 원장 | 4가지 입력 → 일정 보기 |
| S2 | 결과(월별 일정) | 원장 | 12개월 일정 + 한 줄 설명 |
| S3 | 항목 상세(펼침) | 원장 | 설명 조금 더, 근거·참고 |
| A1 | 규칙 편집 | 관리자 | 규칙 추가/수정/끄기 (구글 시트 자체가 편집 화면) |
| A2 | 검수 | 관리자 | 조건 조합별 결과를 한 번에 보고 맞는지 확인 |

S1, S2는 같은 페이지 안에서 전환한다(새로고침 없이). A2는 원장에게 링크를 주지 않는 별도 주소다.

## S1 입력

```
┌──────────────────────────────┐
│  [세무법인 로고]              │
│  우리 병원 1년 세무 일정      │
│  4가지만 알려주세요           │
│                              │
│  개원일 (예정일도 OK)          │
│  [ 2026-11-02          📅 ]  │
│                              │
│  진료과목                     │
│  [ 피부과              ▼ ]   │
│                              │
│  미용 시술을 하시나요?         │
│  ( 예 )  ( 아니오 )           │
│  ⓘ 보톡스, 필러, 레이저 등     │
│                              │
│  직원이 있나요? (예정 포함)    │
│  ( 예 )  ( 아니오 )           │
│                              │
│  [    일정 보기    ]  ← 꽉 찬 버튼│
│                              │
│  입력하신 내용은 저장되지 않습니다│
└──────────────────────────────┘
```

- 4개 다 입력해야 버튼이 활성화된다.
- 진료과목을 고르면 진료과목 탭의 미용기본값으로 미용 시술 답을 미리 골라 둔다(원장이 바꿀 수 있음).

## S2 결과

```
┌──────────────────────────────┐
│ ← 다시 입력                   │
│ [11/2 개원][피부과][미용O][직원O]│ ← 조건 칩
│                              │
│ 2026년 11월                   │
│ ┌──────────────────────────┐ │
│ │ 11/22  사업자등록          │ │
│ │ 개원 후 20일 안에 해야 해요 ⌄│ │
│ └──────────────────────────┘ │
│                              │
│ 2026년 12월                   │
│ ┌──────────────────────────┐ │
│ │ 12/10  원천세 신고·납부    │ │
│ │ 직원 월급에서 뗀 세금 내기 ⌄│ │
│ └──────────────────────────┘ │
│ ...                          │
│ 2027년 1월                    │
│ │ 1/25  부가세 확정신고 [미용]│ │ ← 조건 때문에 생긴 항목 표시
│ ...                          │
│ ──────────────────────────── │
│ 주말·공휴일이면 다음 영업일까지 │
│ 이 일정은 안내용이며 ...       │ ← 면책(설정 탭)
│ 문의: OO세무법인 02-000-0000   │
│ 기준일: 2026-10-01 규칙       │ ← 규칙 마지막 수정일
└──────────────────────────────┘
```

- 월 제목은 화면 위에 붙어 있게(sticky) 한다.
- 지금 달은 강조하고, 지난 날짜는 흐리게 처리한다.
- 항목 태그(미용, 직원)는 "왜 이게 나왔는지"를 보여준다.

## S3 항목 상세 (S2 안에서 펼침)

```
│ 1/25  부가세 확정신고 [미용] ⌃│
│ 미용 시술 매출은 부가세가 붙어요.│
│ 7~12월분을 1월 25일까지 신고해요.│
│ 이 신고를 하면 사업장현황신고는  │
│ 따로 안 해도 돼요.              │
│ 참고: 부가가치세법 제49조       │
```

## A2 검수 (관리자)

```
┌───────────────────────────────────────┐
│ 검수  기준 개원일 [2026-11-02]          │
│ 과목 [전체▼]                            │
│                                       │
│          미용N직원N 미용N직원Y 미용Y직원N 미용Y직원Y│
│ 사업자등록    ●        ●        ●        ● │
│ 원천세(매월)  -        ●        -        ● │
│ 사업장현황    ●        ●        -        - │
│ 부가세확정    -        -        ●        ● │
│ ...                                   │
│ [조합 하나 클릭 → S2 화면 그대로 미리보기] │
└───────────────────────────────────────┘
```

- 폰보다 PC에서 볼 화면이라 표 형태로 둔다.
- 규칙에 오류가 있으면(필수 칸 빈칸, 날짜 형식 오류) 맨 위에 빨간 목록으로 보여준다.
