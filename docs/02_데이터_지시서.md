# 02. 데이터 지시서 (규칙 표)

목표: 관리자가 **엑셀 한 줄 고치듯** 세법 변경을 반영한다.
규칙은 표 한 장에 들어 있고, 한 줄이 일정 하나를 만든다. 코드는 이 표를 읽기만 한다.

## 1. 규칙 표 칸 정의

| 칸 | 필수 | 값 예시 | 뜻 |
|---|---|---|---|
| id | ○ | `VAT_2ND_FINAL` | 바꾸지 않는 고유 이름(영문) |
| 사용 | ○ | `Y` / `N` | N이면 잠시 끔(삭제 대신) |
| 상태 | ○ | `확정` / `예시(검수 전)` | 검수 화면에서 구분 표시 |
| 세목 | ○ | `부가세` | 묶음/색깔용 |
| 이름 | ○ | `부가세 확정신고(2기)` | 화면 제목 |
| 한줄설명 | ○ | `7~12월 미용 매출 부가세 신고` | 결과 화면 기본 문구(40자 이내 권장) |
| 상세설명 |  | 긴 설명 | 펼쳤을 때 |
| 근거 |  | `부가가치세법 제49조` | 펼쳤을 때 |
| 기한유형 | ○ | 아래 표 | 날짜를 만드는 방식 |
| 기한값 | ○ | `01-25` | 기한유형에 따라 해석 |
| 조건_미용 | ○ | `Y` / `N` / `*` | `*` = 상관없음 |
| 조건_직원 | ○ | `Y` / `N` / `*` | |
| 조건_과목 | ○ | `*` 또는 `피부과,성형외과` | 쉼표로 여러 과목. 과목명은 진료과목 탭과 정확히 같아야 함 |
| 시작연차 |  | `2` | 개원 몇 년차부터 적용(개원 연도=1년차. 예: 중간예납은 첫해 없음) |
| 시작개월 |  | `1` | 개원월 몇 달 뒤부터 적용(예: 원천세는 개원 다음 달부터) |
| 적용시작일 |  | `2027-01-01` | 세법 시행일. 이 날짜 이전 기한에는 안 나옴 |
| 적용종료일 |  | `2026-12-31` | 폐지·변경 전 규칙 |
| 메모 |  | | 관리자용, 화면에 안 나옴 |

> **세법이 바뀌면**: 옛 줄의 `적용종료일`을 채우고, 새 줄을 `적용시작일`과 함께 추가한다. 옛 줄을 지우지 않으므로 이력이 남고, 시행일 전후 일정이 자동으로 맞게 나온다.

## 2. 기한유형

| 기한유형 | 기한값 형식 | 예 | 결과 |
|---|---|---|---|
| `매년` | `MM-DD` 또는 `MM-말일` | `05-31` | 매년 5/31 |
| `매월` | `DD` 또는 `말일` | `10` | 매월 10일 |
| `개원일+일` | 숫자 | `20` | 개원일+20일 (1회) |
| `개원월말+개월` | 숫자 | `3` | 개원한 달 말일부터 3개월 뒤 말일 (1회) |
| `개원전` | 숫자(일) | `30` | 개원일 N일 전 준비 항목 (1회) |

새 유형이 필요하면 관리자가 요청 → 개발 수정(드문 경우로 본다).

시트가 값을 바꿔 내보내도 읽을 수 있게 다음 형식도 받는다.
- 날짜: `2026. 10. 11`, `2026/10/11`, `10/11/2026`
- 매년 기한값: `1월 25일`, `2026. 1. 25`, `1/25/2026`(연도는 무시)
- Y/N 칸: 체크박스(`TRUE`/`FALSE`), `예`/`아니오`

반복 일정(매년·매월)은 개원일 이후 날짜만 나온다. 1회성 일정은 표시 기간 시작 전이어도 나온다.

## 3. 보조 표

- **진료과목**: `과목명, 미용기본값(Y/N)`. 입력 화면 드롭다운용.
- **설정**: `세무법인명, 연락처, 면책문구, 규칙기준일`.

## 4. 예시 규칙 (전부 `예시(검수 전)`, 관리자 검수 필수)

Claude가 일반적인 내용으로 채운 초안이다. **날짜·조건·면제 여부는 관리자가 확인하기 전까지 사실로 쓰지 않는다.**

| id | 이름 | 기한유형 | 기한값 | 미용 | 직원 | 시작연차 | 한줄설명 |
|---|---|---|---|---|---|---|---|
| BIZ_REG | 사업자등록 | 개원일+일 | 20 | * | * | | 개원 후 20일 안에 등록 |
| CASH_RCPT | 현금영수증 가맹 | 개원월말+개월 | 3 | * | * | | 의료업은 의무 가맹 업종 |
| WHT_MONTHLY | 원천세 신고·납부 | 매월 | 10 | * | Y | | 지난달 월급에서 뗀 세금 내기 |
| DAILY_WAGE | 일용근로 지급명세서 | 매월 | 말일 | * | Y | | 일용직 지급 내역 제출 |
| YEAR_END | 연말정산 신고 | 매년 | 03-10 | * | Y | 2 | 직원 연말정산 결과 신고 |
| INS_TOTAL | 4대보험 보수총액신고 | 매년 | 03-15 | * | Y | 2 | 지난해 직원 급여 총액 신고 |
| BIZ_STATUS | 사업장현황신고 | 매년 | 02-10 | N | * | 2 | 면세 병원의 1년 매출 신고 |
| VAT_1ST | 부가세 확정신고(1기) | 매년 | 07-25 | Y | * | | 1~6월 미용 매출 부가세 |
| VAT_2ND | 부가세 확정신고(2기) | 매년 | 01-25 | Y | * | 2 | 7~12월 미용 매출 부가세 |
| VAT_PRE_1 | 부가세 예정고지 납부 | 매년 | 04-25 | Y | * | | 고지서 오면 납부 |
| VAT_PRE_2 | 부가세 예정고지 납부 | 매년 | 10-25 | Y | * | | 고지서 오면 납부 |
| INCOME_TAX | 종합소득세 신고 | 매년 | 05-31 | * | * | 2 | 지난해 소득 신고(성실신고 대상은 6/30) |
| INCOME_MID | 종소세 중간예납 | 매년 | 11-30 | * | * | 2 | 고지서로 반만 미리 납부 |
| LICENSE_TAX | 등록면허세 | 매년 | 01-31 | * | * | 2 | 의료기관 면허세(지방세) |
| RESIDENT_TAX | 주민세(사업소분) | 매년 | 08-31 | * | * | 2 | 사업장 주민세(지방세) |

검수 때 특히 확인할 점:
- 미용 병원(겸영)의 사업장현황신고 면제 처리, 부가세 예정고지 대상 여부
- 간이지급명세서(근로) 제출 주기(세법 개정 일정에 따라 달라짐), 원천세 반기납부 처리
- 성실신고확인대상 분기(입력 항목이 없으면 설명 문구로만 처리)
- 사업용계좌 신고, 면세사업자 계산서합계표 등 빠진 항목
